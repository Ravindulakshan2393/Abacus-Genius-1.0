# Abacus Genius 1.0

An Arduino Mega based smart abacus learning system with:

- LCD Display
- Keypad Input
- DFPlayer Audio
- LED Feedback
- Vibration Feedback
- ESP8266 WebSocket Connectivity
- Auto/Manual Math Quiz Modes

## Hardware
- Arduino Mega
- ESP8266
- DFPlayer Mini
- I2C LCD
- Matrix Keypad
- PIR Sensor
- Touch Sensor
- LEDs
- Coin Vibration Motor
